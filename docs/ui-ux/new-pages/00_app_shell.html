Navigation structure
Sidebar groups are stable. Pages are either Aggregated dashboards, Raw lists, or Live feeds.
Overview: Dashboard (Agg), Analytics (Agg) Observe: Devices (Raw), Sessions (Raw), API Traces (Raw), Logs (Raw), Crashes (Agg→Raw), Live Debug (Live) Control: Business Config, Localization, Builds Operate: Alerts, Monitoring (Agg) Developer: SDK Settings, API Keys, Mocking Organization: Team, Billing, Settings
Non-negotiables (performance + privacy)
  • Raw pages: server pagination + indexed filters (no full scans).
  • Dashboard pages: aggregates only (rollups/materialized views).
  • Live Debug: delta fetch since last timestamp; max window 24h.
  • Request/response bodies: fetched lazily + masked by policy.
Incremental migration plan (to avoid breaking current UI)
  1. Introduce new layout shell and theme tokens behind a feature flag.
  2. Wrap existing pages in new shell (no functional change).
  3. Replace only page header + FilterBar first.
  4. Replace table to shared DataTable component (keep same API calls).
  5. Add drawers and lazy-fetch bodies (API traces/logs) using existing endpoints.
