Features

Built for two realities: real-time debugging and product insights.

🔍

Raw Debug Mode

For debug-enabled devices: stream logs, traces, sessions, and screen flow events in near real-time. Device-scoped filters, live tail, and session timeline linking.

📈

Aggregated Dashboards

Stable charts and KPIs from aggregated metrics. Latency percentiles, error rate, crash-free sessions. Drill down into raw rows when needed.

Observability

Trace - Logs - Sessions - Crashes, unified by session/device context.

⚡

API Tracing

Monitor every HTTP request/response with full headers, bodies, status codes, and response times in real-time.

📝

Remote Logging

Stream logs from any device with full context. Filter by level, search by content, and debug issues faster.

💥

Crash Reports

Catch crashes with full stack traces. Know exactly what went wrong, on which device, and when.

📊

Session Timeline

Track complete user sessions with screen flow, API calls, and logs. Understand user journeys.

🗺

Screen Flow

Navigation path analysis and drop-off points. See exactly how users move through your app.

💻

Device Info

Full device context: model, OS version, app version, locale, and custom properties.

Remote Configuration

Ship changes safely. Audit every change. Roll back fast.

🎯

Feature Flags

Remote feature toggles and SDK control. Enable/disable features without app updates.

⚙️

Remote Config

Manage app configurations remotely. Key-value store with multiple types. No deployments needed.

🌐

Localization

Manage translations remotely. Glossary support, multiple providers, import/export.
